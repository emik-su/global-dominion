# GLOBAL DOMINION — сетевая игра

3D-стратегия, в которую можно играть по сети с друзьями из любой точки мира — друг против друга или вместе против ИИ. Работает в браузере (телефон и компьютер) и как мини-приложение Telegram.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | сама игра (одна страница, всё внутри) |
| `room.js` | комнаты: лобби, места, старт боя, раздача ходов |
| `worker.js` | сервер для Cloudflare (бесплатно, работает по всему миру) |
| `wrangler.toml` | настройки Cloudflare (имя, комнаты, ссылка на бота Telegram) |
| `server.js` | тот же сервер для своего компьютера или VPS (Node.js 18+) |
| `package.json` | описание проекта |

## Как устроена сетевая игра

Сервер не считает бой — он только принимает приказы игроков и каждые 100 мс рассылает всем один и тот же «ход» со списком приказов. Игра у каждого участника считает бой одинаково (общие случайные числа и одинаковая математика на всех устройствах), поэтому по сети идут только приказы — несколько сотен байт в секунду, хватает и мобильного интернета. ИИ-боты считаются у всех участников одинаково.

- Приказ выполняется примерно через 0,2–0,4 с (дорога до сервера и обратно) — звук и метка видны сразу.
- Раз в полсекунды игры сверяют контрольную сумму состояния; если что-то разошлось, появится предупреждение.
- Пропала связь — бой продолжается; через 30 с войсками игрока командует ИИ. Вернулся (та же вкладка) — получает пропущенные ходы и снова командует.
- Бой никого не ждёт: игрок с плохой связью или слабым телефоном видит бой с задержкой и догоняет его; отстал больше чем на 15 с — его войсками временно командует ИИ, догнал — снова командует сам. Уход хоста бой не останавливает, хостом комнаты становится другой участник.
- Все видят всплывающие сообщения: «… потерял связь», «… снова на связи», «… без связи — войсками командует ИИ», «… вернулся в игру».
- Инструментов разработчика (создать войска, кредиты, ускорить стройку) в сетевой игре нет — только в одиночной. Для автотестов синхронизации локальный сервер принимает их при запуске с `GD_TEST_DBG=1` (воркер Cloudflare — никогда).
- Пауза в сетевой игре не останавливает бой; скорость всегда 1×.
- **Открытые комнаты.** Хост задаёт название и включает «Открытая комната» — комната видна всем в списке «Открытые комнаты» (на экране «Сетевая игра»): «Войти» — на свободное место, «Смотреть» — зрителем. Список держит сам сервер (`/rooms`; на Cloudflare — отдельный объект `__dir__` того же класса, настраивать ничего не нужно).
- **Зрители** мест не занимают, видят всю карту без тумана войны, но с задержкой 1 минута — сервер присылает им ходы на 600 позже, так что подсказать игрокам «со второго телефона» нельзя. Панель наблюдателя: участники, войска, здания, кредиты; «Вид» — вся карта или глазами любого игрока.
- **«Сдаться»** (меню в бою): база выбывает, бой можно смотреть дальше — пока жив союзник, только то, что видит союз.
- Выбирать страну и цвет можно одновременно: строка, в которой игрок сейчас выбирает, не перерисовывается от чужих изменений.
- **Чат:** «Все» — всем в комнате и в бою (и зрителям), «Команда» — только своему союзу (в комнате — по союзу места, в бою — по союзу игрока), зрители во время боя пишут только зрителям. Сервер пропускает не больше 2–3 сообщений в секунду от одного человека.
- **Командные метки** («Атаковать», «Цель», «Нужна помощь») идут как обычные приказы: приходят всем в один ход, видят их союзники (и зрители), ИИ-союзник откликается у всех одинаково.
- **Тайное оружие** снимает туман войны над зоной удара у всех участников (до конца удара и ещё 20 с) — это часть боя, одинаковая у всех.

## Разместить бесплатно (с телефона)

1. **GitHub.** github.com → Sign up. Затем «+» → New repository → имя `global-dominion` → Create repository. На странице репозитория — «uploading an existing file» → выбрать все файлы из этой папки → Commit changes.
2. **Cloudflare.** dash.cloudflare.com → Sign up. Затем Workers & Pages → Create → Import a repository (GitHub) → разрешить доступ → выбрать `global-dominion` → Deploy. Через 1–2 минуты появится адрес вида `https://global-dominion.<имя>.workers.dev` — это сайт игры.
3. **Telegram.** @BotFather → `/mybots` → ваш бот → Bot Settings → Configure Mini App → Enable Mini App → отправить адрес сайта. Там же Menu Button → тот же адрес, название «Играть».

Ссылка на бота уже вписана в `wrangler.toml` (`TG_LINK`): приглашения в комнату ведут в Telegram — `https://t.me/RTSGD_bot?startapp=КОД`. Другой бот — поменяйте эту строку.

Обновление игры: загрузите новый `index.html` в репозиторий (Add file → Upload files) — Cloudflare сам обновит сайт.

## Как играть по сети

- **«Сетевая игра» → «Создать комнату»** — вы хост: выбираете карту, правила (кредиты, гипероружие, туман войны, погода, день и ночь) и кто занимает места.
- **«Пригласить друга»** — ссылка в Telegram (или код комнаты из 5 знаков — его можно продиктовать).
- Свободное место можно отдать **ИИ** (лёгкий, средний, сложный) или закрыть.
- **Союзы:** одинаковая «Команда» — союзники. Все люди в «Команде 1», а ИИ в «Команде 2» — вместе против ботов. «Сам за себя» — каждый против всех.
- Каждый выбирает себе фракцию и цвет (цифра на кружке — место на карте). Хост нажимает **«В бой»**. После боя — «В комнату», и можно играть снова.

## Свой сервер (компьютер, локальная сеть, VPS)

```
node server.js
```

Игра откроется на `http://localhost:8787` (в локальной сети — `http://<адрес-компьютера>:8787`). Порт — переменная `PORT`, ссылка Telegram — `TG_LINK`. Для Telegram нужен адрес с `https://`.
